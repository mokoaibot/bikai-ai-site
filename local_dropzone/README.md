# 📥 local_dropzone/

Эта папка — "точка приёма" файлов с вашей локальной машины.

## Как использовать

1. Загружайте сюда файлы вручную (через интерфейс Arena AI) или через
   `python3 sync_git.py pull`, если файл был предварительно закоммичен
   в GitHub-репозиторий с другого компьютера.
2. Поддерживаются любые типы: изображения, SEO-тексты, ТЗ, документы для
   перевода и т.д.
3. По команде в чате Оркестратору (например: «Проверь, какие файлы лежат
   в dropzone» или «Возьми файл brief.docx и передай его агенту-переводчику»)
   субагенты смогут сканировать содержимое этой папки и забирать файлы в
   работу.

## Важно

- Не храните здесь ключи, пароли и `.env` — эта папка синхронизируется
  с GitHub-репозиторием (см. `sync_git.py`), а значит, всё из неё может
  попасть в публичный доступ, если репозиторий публичный.
- Если нужно исключить содержимое dropzone из Git (например, из-за
  больших бинарных файлов), раскомментируйте правило `local_dropzone/*`
  в `.gitignore`.
