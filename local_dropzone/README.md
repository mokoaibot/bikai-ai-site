# 📥 local_dropzone/

Точка приёма файлов с вашей стороны.

## Как использовать

1. Загружайте сюда файлы вручную (через интерфейс Arena AI).
2. Поддерживается всё: изображения, ТЗ, документы для перевода и т.д.
3. Я забираю файлы отсюда и перекладываю в нужную папку —
   `directions/<направление>/raw_inputs/` — чтобы они не лежали
   вперемешку с новыми загрузками.

## Важно

- Не храните здесь ключи/пароли/`.env` — содержимое может попасть в
  GitHub-репозиторий через `python3 engine/sync_git.py push`.
- Если нужно исключить содержимое dropzone из Git (большие бинарники),
  раскомментируйте `local_dropzone/*` в `.gitignore`.
