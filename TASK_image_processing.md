# Задача: унификация фото каталога BIKAI

**Ссылка для просмотра «было/стало» и понимания требований к качеству:**
https://mokoaibot.github.io/bikai-ai-site/catalog-compare.html
(слева — текущие фото с сайта, справа — неудачные попытки автообработки; на них видно,
что НЕДОПУСТИМО: удаление деталей товара, дыры в корпусах, остатки фоновых «островов»).

## Где лежат файлы
- Исходники (НЕ ТРОГАТЬ): `directions/bikai/catalog/images/` — 56 файлов `*.webp`.
- Результат писать сюда: `directions/bikai/catalog/images_new/` — те же имена файлов.
- Каталог товаров для имён/категорий: `directions/bikai/catalog/data/products.json`.

## Требования к каждому изображению
1. Холст 900×900, фон `#f3f8fd` (RGB 243,248,253), товар по центру, занимает ~84% стороны.
2. Формат: webp, quality 85.
3. Убрать: белые/чёрные поля, студийные тёмные градиентные фоны, серые полосы по краям,
   диагональные вотермарки «BIKAICN» (инпейнт цветом окружающего фона).
4. Под товаром — мягкая тень: цвет (15,40,90), alpha ~0.35, blur ~18px, смещение (+6,+26).
5. **ГЛАВНОЕ: товар должен остаться полностью нетронутым** — все детали, провода,
   прозрачное стекло, чёрный пластик, надписи на корпусах. Лучше оставить чуть фона,
   чем потерять пиксель товара.

## Запрещено
- Менять что-либо вне `images_new/` (живой сайт, `images/`, git, коммиты).
- Использовать AI-генерацию/дохудовку товара — только классическая обработка
  (маски, инпейнт фона, кроп, композит).

## Результат
Папка `directions/bikai/catalog/images_new/` с 56 обработанными webp —
дальше её забирает основной агент и выкладывает на страницу сравнения.
