## Как собрать сцену

1. Холст 1600×900, положите `background-studio-1600x900.png`.
2. Расставьте вырезы справа (левая ~половина — под заголовок с тёмным градиентом сайта).
3. Под каждый объект — мягкая тень (чёрная, blur 10–14, opacity 10–30%).
4. Экспорт JPG, качество 88 → положите в `bikai.by/site/assets/hero/<slug>.jpg`
   (имена: `chromatography.jpg`, `mass-spectrometry.jpg`, `spectroscopy.jpg`, `consumables.jpg`)
   и пересоберите сайт: `python3 scripts/build_site.py`.
