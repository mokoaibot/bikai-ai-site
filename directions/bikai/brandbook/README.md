# Брендбук BIKAI

Материалы по фирменному стилю бренда. Задачи — из проектного плана
(«Брендбук и маркетинговые материалы»).

## Логотип (`logo/`)

- **Задача:** перерисовать логотип BIKAI в векторе, несколько вариантов
  на согласование.
- **Источник:** `directions/bikai/catalog/bikai_telegram_logo.png`
  (2048×2048, растр — текущий логотип Telegram-канала бренда).
  Белые поля обрезаны, фон в векторе прозрачный.
- **Фирменные цвета** (сняты с растра, нормализованы в векторе):
  - тёмный фиолетовый `#461EB2`
  - светлый фиолетовый `#7D64E6`
- **Варианты:**
  - `logo/bikai-logo-v1-color.svg` — точная трассировка, 2 цвета (основной)
  - `logo/bikai-logo-v2-simplified.svg` — упрощённая геометрия, 7 путей
    (для мелких размеров: фавикон, аватар, печать мелким кеглем)
  - `logo/bikai-logo-v3-monochrome.svg` — одноцветный, `currentColor`
    (гравировка, тиснение, одноцветная печать; цвет задаётся снаружи)
  - `logo/bikai-logo-v4-lockup-wordmark.svg` — знак + слово «BIKAI»
    (черновик: шрифт задан текстом, в кривые не переведён)
- **Статус:** варианты переданы заказчику на валидацию (заказчик —
  главный валидатор). После выбора основной вариант пойдёт в шапку
  сайта и материалы бренда.
