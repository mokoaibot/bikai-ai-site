# Брендбук BIKAI

Материалы по фирменному стилю бренда. Задачи — из проектного плана
(«Брендбук и маркетинговые материалы»). Заказчик — главный валидатор
логотипа. Витрина всех вариантов: `index.html` в этой папке
(self-contained, открывается в браузере и в превью Arena).

  файлы v1–v4 (svg/png) и исходный растр `catalog/bikai_telegram_logo.png`.
  Оригиналы остаются в истории git.

  завода) + новые концепты знаков без «волн».

## Концепты на валидации (`logo/svg/bikai-logo-concept-*`)

Чистая геометрия, без волн:

1. `concept-1-hexagon` / `concept-1-lockup` — гексагон (химия) + пик
   хроматограммы.
2. `concept-2-bars` / `concept-2-lockup` — спектральные полосы.
3. `concept-3-peak-underline` — wordmark + пик-подчёркивание.

PNG-превью всех векторов — в `logo/png/` (рендер cairosvg, белый фон,
если в имени есть `white`).
