03 · Типографика

Myriad Pro — с веб-эквивалентом Source Sans 3

Как и Mindray, бренд использует humanist-гротеск: заголовки — лёгкие (400/600), без капслока, крупного кегля; секции открываются красным кикером. В вебе Myriad Pro заменяется открытым Source Sans 3 (встроен в эту страницу).

Кикер секции · 15/600 · красный
H1 — 44–60 px, weight 400, line-height 1.12
H2 — 30–36 px, weight 600
Текст — 16 px, #727171, line-height 1.6. Абзацы не длиннее 720 px, чтобы сохранялась читабельность каталога и сервисных страниц.
Капшн · 12 px · uppercase · letter-spacing .06em

Подвал (footer)

Фон Paper, верхняя линия Line; 4 колонки: логотип + лид, разделы, реквизиты, контакты. Заголовки колонок — капшн 12 px uppercase, ссылки — Gray 14 px, hover Red. Нижняя строка: © + реквизитная строка и обязательная ссылка «Брендбук» (Gray, hover Red) — вход в дизайн-систему всегда с сайта.

Контейнер 1160 px, 12 колонок, желоб 24 px, поле 24 px. Секции разделяются линией 1px #DCDDDD; вертикальный ритм — 64/96 px.

Отступы

4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 px. Внутри карточек — 24–32 px, между карточками — 24 px, между секциями — 96 px.
06 · CSS-токены

Готовый блок :root для сайта и каталога

:root{
  /* BIKAI design tokens · v2 · по мотивам дизайн-языка Mindray */
  --red:#F02F1D;        /* фирменный красный: CTA, акценты, кикеры */
  --red-dark:#C21F10;   /* hover для красного */
  --red-deep:#9B0000;   /* активное состояние, тёмные акценты */
  --ink:#242728;        /* заголовки H2 и ниже */
  --ink-strong:#171515; /* H1, дисплейные надписи */
  --logo-black:#050505; /* цвет wordmark логотипа */
  --gray:#727171;       /* основной текст */
  --line:#DCDDDD;       /* линии, бордеры карточек */
  --paper:#FAFAFA;      /* фон секций */
  --white:#FFFFFF;      /* базовый фон */
  --font-brand:"Myriad Pro","Source Sans 3","Segoe UI",Helvetica,Arial,sans-serif;
  --s1..--s9: 4/8/12/16/24/32/48/64/96px;  /* шкала отступов */
  --radius:0px;         /* острые углы, как в Mindray */
}
