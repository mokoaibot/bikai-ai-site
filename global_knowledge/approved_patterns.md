# ✅ Успешные паттерны (Approved Patterns)

Этот файл — глобальная база знаний системы. Сюда Оркестратор и субагенты
записывают проверенные решения и подходы, которые хорошо себя показали.
Новые записи добавляются автоматически через команды в чате, например:
«Запомни паттерн: ...».
